# Установка во внутренний контур

Инструкция для ИТ и службы безопасности. Маска состоит из одного файла `index.html`. Сервера приложений, базы данных, учётных записей и обращений в интернет у неё нет, поэтому установка сводится к тому, чтобы доставить файл до пользователей.

## Что нужно

- Файл `index.html` из этого репозитория, около 200 КБ.
- Браузер с поддержкой `DecompressionStream('deflate-raw')` и ретроспективных проверок в регулярных выражениях. По таблицам совместимости это Chrome, Edge и Яндекс Браузер с версии 103, Firefox с 113, Safari с 16.4. Руками проверен Chromium. В браузере старше Маска откроется, но docx и xlsx не прочитает.
- Node.js 24 нужен только для проверки перед установкой (тесты и сборка). Пользователям он не нужен.

## 1. Получить и зафиксировать версию

```sh
git clone https://github.com/alexandr-komarov/maska.git
cd maska
git log -1 --format='%H %ad'     # хеш коммита, который вы проверяете и ставите
sha256sum index.html            # контрольная сумма для реестра ПО
```

Если в контуре нет доступа к GitHub, скачайте ZIP со страницы репозитория (Code, Download ZIP) на машине с интернетом и перенесите его принятым у вас способом. Хеш коммита и `sha256sum index.html` запишите в заявку на установку: по ним потом видно, что на рабочих местах стоит та же версия, что прошла проверку.

## 2. Проверить перед установкой

```sh
node build.mjs --check          # блок модулей в index.html совпадает с src/
node --test tests/*.test.mjs    # тесты, среди них проверка «без сети» и CSP
```

Тесты, которые открывают результат в LibreOffice, без `soffice` пропускаются.

Что посмотреть глазами:

- В начале `<head>` стоит политика безопасности контента (CSP). Она запрещает странице любые запросы (`connect-src 'none'`), отправку форм (`form-action 'none'`) и загрузку чужих скриптов, стилей и картинок (`default-src 'none'`).
- В файле один блок `<script>` без атрибута `src` и один блок разметки для поисковиков `application/ld+json`, который браузер не выполняет.
- Адреса `https://alexandrkomarov.com` стоят только в `canonical`, `og:`, schema.org и ссылках подвала. Браузер сам по ним не ходит. Если политика требует убрать внешние адреса совсем, удалите строки с ними в `<head>` и подвале. На работу Маски это не влияет, но тест `page.test.mjs` и сверка `sha256sum` с сайтом после этого покажут расхождение, это ожидаемо.

Проверка в браузере: откройте файл, нажмите F12, вкладка Network, загрузите любой docx. В списке запросов будет только сам `index.html`. В консоли выполните `fetch('https://example.com')`, браузер откажет с нарушением `connect-src`.

## 3. Выбрать способ установки

### Файлом на рабочие места

Положите `index.html` в общую папку или раздайте тем способом, которым вы раздаёте документы и ярлыки. Пользователь открывает файл двойным щелчком, страница работает с диска (`file://`).

При открытии с диска браузер может не дать странице доступ к буферу обмена. На этот случай в Маске есть запасной путь копирования через выделение текста, кнопки «Копировать» работают в обоих режимах.

### На внутреннем веб-сервере

Подходит любой сервер статики. Сервер отдаёт только файл страницы, документы пользователей на него не попадают: в журнале доступа будет `GET` самой страницы и, возможно, `favicon.ico`, его браузер запрашивает сам.

CSP уже стоит в самом файле. На сервере её стоит продублировать заголовком и добавить `frame-ancestors 'none'`, которую в `<meta>` указать нельзя: она запрещает встраивать страницу в чужой фрейм.

nginx:

```nginx
server {
    listen 443 ssl;
    server_name maska.corp.local;                 # ваше имя
    # ssl_certificate и ssl_certificate_key по вашим правилам

    root /var/www/maska;                          # здесь лежит index.html
    index index.html;

    location / {
        try_files $uri /index.html;
    }

    add_header Content-Security-Policy "default-src 'none'; script-src 'unsafe-inline'; style-src 'unsafe-inline'; img-src data:; connect-src 'none'; form-action 'none'; base-uri 'none'; frame-ancestors 'none'" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header Referrer-Policy "no-referrer" always;
}
```

IIS, файл `web.config` рядом с `index.html`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<configuration>
  <system.webServer>
    <defaultDocument>
      <files>
        <clear />
        <add value="index.html" />
      </files>
    </defaultDocument>
    <httpProtocol>
      <customHeaders>
        <add name="Content-Security-Policy" value="default-src 'none'; script-src 'unsafe-inline'; style-src 'unsafe-inline'; img-src data:; connect-src 'none'; form-action 'none'; base-uri 'none'; frame-ancestors 'none'" />
        <add name="X-Content-Type-Options" value="nosniff" />
        <add name="Referrer-Policy" value="no-referrer" />
      </customHeaders>
    </httpProtocol>
  </system.webServer>
</configuration>
```

По HTTPS буфер обмена работает напрямую, по HTTP включается тот же запасной путь, что и с диска.

## 4. Что сказать пользователям

- Маска показывает окно проверки, и его нужно просмотреть: правила находят не всё, особенно фамилии без имени и названия фирм без ООО или АО. Названия своих контрагентов, проектов и объектов вписывают в поле «Что ещё спрятать».
- Сейф (`<название>.сейф.json`) содержит настоящие значения. Хранить его нужно там же и так же, как исходные документы, и не отправлять в нейросеть.
- В нейросеть уходит только скачанный обезличенный файл или текст с метками. Какой нейросетью пользоваться и можно ли вообще, решает ваша политика, Маска это не контролирует.

## 5. Обновление и удаление

Обновление делается заменой `index.html`. Перед заменой повторите шаги 1 и 2 на новой версии и сравните `git log` между старым и новым хешем.

Чтобы удалить Маску, удалите файл. Маска не пишет в `localStorage`, `IndexedDB` и cookie, ничего не ставит в систему и следов в браузере, кроме обычной истории посещений, не оставляет.

## Если что-то не работает

- docx или xlsx не открывается, а текст вставляется: браузер старше версий из раздела «Что нужно».
- Файл doc или xls: Маска их не читает, пересохраните в docx или xlsx.
- Страница на сервере открывается без стилей или не работает кнопка: на сервере стоит своя CSP без `'unsafe-inline'`. Для Маски нужна политика из примера выше.
